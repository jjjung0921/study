# 다른 컴퓨터에서 RAG 학습 이어가기

GitHub 저장소: https://github.com/jjjung0921/study

## 저장과 실행

GitHub는 학습 파일을 동기화하는 원본이고, Codex Cloud는 해당 파일로 학습하는 실행 환경이다. 이 대화 자체와 로컬의 미커밋 파일은 저장소 연결만으로 복사되지 않는다. 새 환경은 GitHub에 반영된 버전부터 시작한다.

클라우드 환경에서 위 저장소를 선택한다. 저장소 이름은 study지만 루트가 RAG subject 하나다. RAG 하위 폴더로 다시 이동하지 않는다.

## 시작할 때 전달할 말

> 이 저장소의 AGENTS.md를 따르고 .ai/CURRENT.md와 .ai/HANDOFF.md에서 중단 지점을 확인해 한국어로 학습을 이어가 줘. 시작 절차를 실행하고, 아직 읽지 않은 내용을 읽었다고 간주하지 마. 학습 기록은 파일로 남겨 줘. GitHub push 전에는 물어봐.

기본 학습 예산은 LEARNER.md를 따른다. 현재 중단 지점은 Phase 02 U6, Lewis 등의 원 RAG 논문 Introduction과 Figure 1이다. 이 안내보다 CURRENT와 HANDOFF의 최신 상태를 우선한다.

## 실행 요구 사항과 경계

- 시작·기록 검사는 Git, Bash, Python 3을 준비하고 저장소 루트에서 실행한다. 초기 학습에 GPU나 모델 가중치 다운로드는 필요하지 않다.
- 이 컴퓨터의 전역 스킬, Claude 채점자 정의, 로그인, 연결 도구는 GitHub로 복제되지 않는다. 클라우드에서도 제공되는지 별도로 확인한다.
- 독립 Claude 채점과 별도 Codex 리뷰가 준비되지 않았다면 정식 채점을 pending으로 남긴다. 메인 튜터가 대신 채점하여 concept state를 올리지 않는다.
- 논문 접근과 인터넷 연결은 클라우드에서 실제로 확인한다. Mac 캘린더와 로컬 사진 원본은 별도로 접근을 준비한다.
- API 키·로그인 토큰을 저장소나 채팅에 복사하지 않는다. 필요한 인증은 서비스의 보안 설정에서 수행한다.

## 컴퓨터를 바꿀 때

1. 종료 전에 학습 문서, exercise, 채점 근거와 CURRENT/HANDOFF를 저장하고 관련 검사 후 커밋한다.
2. GitHub 반영 승인을 받은 뒤 업로드한다. 클라우드 작업이 별도 브랜치나 PR에 저장됐다면 다음 환경이 그 변경을 포함하는지 확인한다.
3. 다음 컴퓨터에서는 최신 변경을 받은 뒤 시작한다. 같은 학습 파일을 두 환경에서 동시에 수정하지 않는다.

공개 저장소에는 업로드한 학습자 정보와 답안도 공개된다. 비공개 전환은 별도 선택이며, 이미 공개된 이력의 회수를 보장하지 않는다.
